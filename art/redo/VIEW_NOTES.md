# Star view: the code-drawn parts in the kit's style

**Built in 0.2.0** (owner: all nine, tag mark B the branded star). What follows is the proposal as it was shown; the code is in `client/Frames`, `Horizon`, `PixelGrid`, `GridTextures`, `sky/MilkyWay` and `StarViewRenderer` (see CLAUDE.md). The real renders are `previews/shots`.

Pictures: `previews/view/1..8_*.png`, painted by `python tools/art_redo/view_mock.py` over the real offline shots
(`previews/redo/shots`). Each scene's projector comes from `previews/view/params.txt`, which
`tools/hudshots/SkyShots.java` now writes beside its shots (the only Java touched, a tool). **No mod Java changed.**
Every painter in `view_mock.py` works per GUI pixel the way the Java would, so each ports almost line for line.

Nothing here has been seen in game. The per-pixel sky and iris are heavier than today's per-row fills; that is the
first thing to watch (FPS in the view at GUI scale 2 and auto).
